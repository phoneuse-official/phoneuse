# Targeting benchmark record

The default task is in `default-benchmark-prompt.txt`. Record every benchmark run
below, including incomplete and failed runs. Compare OCR and accessibility using
the same prompt, starting screen, limits, and environment where possible. Record
differences that affect comparability. Use elapsed wall time from task start to
completion or stop; do not present a partial run as a completion.

For each run, record the date, method, prompt version or hash, environment (without
device identifiers), starting conditions, elapsed time, outcome and stop reason,
and progress: number of products researched, specifications verified per product,
source URLs, and whether a comparison and recommendation were produced. Record
errors, retries, and relevant configuration. Assess accuracy against the cited
sources before declaring a winner. Summarize a comparison only after both runs;
explain any unequal capabilities or conditions.

Do not record screenshots, personal data, tokens, device identifiers, or task
history from unrelated activity. Follow the project's live-device testing rules.
